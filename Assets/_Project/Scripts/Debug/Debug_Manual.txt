=====================================================
스테이지 씬 디버그
=====================================================
1. 재화 치트
 - F1 : 마석 파편 +1,000 추가
 - F2 : 완전한 마석 +10 추가
 - F3 : 모든 재화 0으로 초기화

2. 인벤토리
 - F4 : 인벤토리 초기화

3. 웨이브 제어
 - F5 : 다음 웨이브 강제 시작 (대기 시간/적 생존 무시)
 - F6 : 필드 내 모든 적 즉시 처치 (재화 지급됨)
 - F7 : 베리어 무적 활성화 / 비활성화 (누를 때마다 전환)

4. 시스템 모니터링
- F10 : 디버그 오버레이 토글 (화면 왼쪽 하단)
	남은 적 수: 현재 필드에 생존해 있는 적의 마릿수 표시
	웨이브 남은 시간: SO에 설정된 전투 제한 시간 카운트다운
	현재 성능: 1초 주기로 갱신되는 평균 FPS 출력
